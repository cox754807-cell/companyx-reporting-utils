# Company X Finance Portal Utilities

Internal support utilities for the fictional **Company X** reporting and finance portal.

This repository is part of an authorised OSINT training environment. All company names,
storage locations, project names and financial artefacts are fictional. No credentials
or live private data are included.

## Components
- reporting service
- archive migration configuration
- finance export utilities
- public web configuration
- test fixtures

## Notes
Some older integrations remain referenced while migration work is completed. Do not
assume every endpoint in the repository is current or controlled by Company X.
