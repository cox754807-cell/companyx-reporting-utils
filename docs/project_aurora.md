# Project Aurora

Project Aurora is the internal name used for the 2026 reporting migration.

The project consolidates reporting exports across several cloud-storage services.
Current configuration references the AWS finance export bucket and associated
quarterly export path.

The repository identifies only the application's currently configured export.
Other objects that may exist within the storage environment are not documented here.

A storage reference in source code should be treated as an investigative lead,
not proof of current existence, ownership or accessibility.
